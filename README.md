# Udai Kothi — Luxury Heritage Boutique Hotel (Avartana Labs Concept)

> **Live Showcase**: [https://avartanalabs.github.io/udai-kothi-sample-avartana/](https://avartanalabs.github.io/udai-kothi-sample-avartana/)

A bespoke luxury web experience engineered by **[Avartana Labs](https://avartanalabs.com)** for **Udai Kothi**, a boutique heritage hotel perched on Hanuman Ghat, Lake Pichola, Udaipur, Rajasthan.

---

## 💎 The Engineering & Design Highlights

1. **Sub-second Performance (<0.4s DOM Delivery)**:
   - Hand-crafted zero-framework HTML5/CSS3/ES6 architecture with zero heavy library overhead.
   - Fully bundled, modern WebP responsive imagery replacing fragile third-party hotlinks.
2. **Interactive Luxury Booking Drawer**:
   - Integrated room selector (Maharani Suite, Heritage Deluxe, Udai Suite, Royal Room, Baro Masi Rooftop Dining).
   - Date pickers and guest selectors with direct pre-filled VIP WhatsApp Concierge inquiry routing (`wa.me`).
3. **60fps / 120fps Buttery Motion**:
   - Custom dual-ring cursor with `requestAnimationFrame` linear interpolation (lerp).
   - Reactive preloader with instantaneous graceful slide transition.
   - Smooth horizontal card carousel with snapping and touch swipe support.
4. **Avartana Labs Pitch Brief**:
   - Integrated pitch badge comparing legacy WordPress hotel stacks (4.8s load, 18-25% OTA commissions, plugin bloat) against Avartana's high-craft, zero-lock-in modern digital architecture.
